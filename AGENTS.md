# Distribution + Social Tracker

Read `README.md` first. If the person hasn't set this up yet: explain it to them using the
"How it works" section of `README.md`, then follow `SETUP.md` from top to bottom without
skipping or improvising.

For later changes, use the "Day-to-day recipes" in `SETUP.md`. Each app has its own rules in
`distribution/CLAUDE.md` and `social_tracker/CLAUDE.md`.

- Every push to `main` deploys to the live server within about 2 minutes.
- Never commit `.env` files, passwords, API keys, videos or pictures.
- Keep the person's copy of this repo private.
